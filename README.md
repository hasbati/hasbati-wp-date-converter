# Hasbati WP Date Converter

**Hasbati WP Date Converter** is a powerful and efficient WordPress plugin designed to simplify Hijri–Gregorian date conversion for Arabic websites and digital platforms. It provides a practical solution for integrating Islamic and Gregorian calendar conversion into WordPress projects, helping website owners deliver a more accessible and localized experience to their visitors.

Developed and maintained as an open-source project by **[Hasbati](https://hasbati.com/)**, the plugin aims to make calendar conversion easier to integrate into Arabic web environments while supporting the needs of websites that work with both date systems.

## Key Features

- **Hijri–Gregorian Date Conversion:** Provides functionality for converting dates between the Islamic Hijri and Gregorian calendar systems.
- **WordPress Integration:** Designed to bring calendar conversion capabilities directly into WordPress websites.
- **Arabic Language Support:** Tailored for Arabic-language websites and platforms, offering a more accessible experience for Arabic-speaking audiences.
- **Practical Calendar Functionality:** Helps simplify date handling for websites that rely on both Hijri and Gregorian dates.
- **Open-Source Development:** Makes the project source code available for developers to explore, use, and adapt according to the applicable license.
- **Maintained by Hasbati:** Developed and maintained by Hasbati, with a focus on practical online tools and utilities.

## Designed for Arabic Web Platforms

The Hijri calendar plays an important role in everyday life across many Arabic-speaking communities. For websites serving these audiences, supporting both Hijri and Gregorian dates can improve usability and make date-related information more relevant to visitors.

**Hasbati WP Date Converter** addresses this need by bringing calendar conversion functionality into the WordPress environment, making it a useful addition to Arabic websites, online services, and content platforms.

## Use Cases

The plugin is suitable for WordPress projects that need to:

- Convert dates between Hijri and Gregorian calendars.
- Provide date conversion functionality to Arabic-speaking visitors.
- Integrate Islamic calendar support into website features.
- Display or process dates using different calendar systems.
- Enhance the user experience of Arabic websites and digital services.
